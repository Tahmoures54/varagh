# سیستم کنترل حمل ورق فولادی از فراسکو (Varagh)

وب‌اپلیکیشن Flask برای ثبت و کنترل هر کامیون از زمان ورود به لیدان فراسکو تا خروج، ثبت وزن اسنادی و وزن‌های باسکول، محاسبه وزن خالص و اختلاف، و نگهداری وضعیت قبض‌های باسکول.

## قابلیت‌ها

- **ثبت حواله**: تمام فیلدهای مشخص‌شده (اطلاعات حواله، ورود/خروج، باسکول، وضعیت کنترل)
- **محاسبات خودکار**:
  - وزن خالص باسکول = وزن پُر − وزن خالی
  - اختلاف وزن = وزن خالص − وزن اسنادی
  - درصد اختلاف
  - مدت توقف (ساعت)
  - وضعیت قبض‌ها (کامل / ناقص)
- **داشبورد**: تعداد حواله‌ها، مجموع وزن‌ها، بالانس، مغایرت‌ها، مدت توقف و لیست موارد نیازمند پیگیری
- **ایندکس موجودی ورق‌ها**: لیست کامل کد کالا، ضخامت، گرید، موجودی، تعداد شیت و موقعیت (لیدان / ساب استیشن)
- **خروجی اکسل**: دانلود فایل اکسل از حواله‌های ثبت‌شده
- **جستجو و فیلتر** بر اساس شماره حواله، پلاک، راننده، کالا و وضعیت

## نصب و اجرا

```bash
# کلون مخزن
git clone https://github.com/Tahmoures54/varagh.git
cd varagh

# محیط مجازی (پیشنهادی)
python -m venv venv
source venv/bin/activate   # ویندوز: venv\Scripts\activate

# نصب وابستگی‌ها
pip install -r requirements.txt

# اجرا
python app.py
```

سپس در مرورگر به آدرس زیر بروید:

```
http://127.0.0.1:5000
```

پایگاه داده SQLite به صورت خودکار در پوشه `data/varagh.db` ساخته می‌شود و داده‌های ایندکس موجودی و چند حواله نمونه بارگذاری می‌شوند.

### دستور CLI برای مقداردهی مجدد دیتابیس

```bash
flask --app app init-db
```

## ساختار پروژه

```
varagh/
├── app.py              # اپلیکیشن اصلی Flask و routeها
├── models.py           # مدل‌های SQLAlchemy (Havaleh, Inventory)
├── requirements.txt
├── README.md
├── data/               # فایل دیتابیس SQLite (ساخته می‌شود)

│   ├── base.html
│   ├── index.html      # داشبورد
│   ├── havaleh_list.html
│   ├── havaleh_form.html

```

## قاعده نهایی سیستم

- هر کامیون یک حواله مستقل دارد
- فقط یک پلاک وسیله ثبت می‌شود
- بارنامه، رسید مقصد و شماره قبض در جدول اصلی جایی ندارند
- قبض‌های باسکول پیوست هستند و با شماره حواله بایگانی می‌شوند
- تمام محاسبات و کنترل‌ها با شماره حواله انجام می‌شوند
