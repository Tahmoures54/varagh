## نصب

```bash
git clone https://github.com/Tahmoures54/varagh.git
cd varagh
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
# اگر از فاز ۱ می‌آیید:
rm -f data/varagh.db
python app.py
```
